# 3D Box Rendering Library Documentation

A Luau utility module for calculating 3D bounding box corner coordinates and rendering 3D filled faces and wireframe outlines on-screen using `DrawingImmediate`.

---

## Quick Start

```luau
local RunService = game:GetService("RunService")
local box3d = loadstring(game:HttpGet("path_to_module"))() -- or require(path)

local targetPart = workspace:WaitForChild("Part")

RunService.RenderStepped:Connect(function()
    -- 1. Calculate 3D corner coordinates from BasePart
    local corners3D = box3d.outline(targetPart)
    
    -- 2. Project 3D positions to 2D screen space
    local screenPoints = box3d.screen_positions(corners3D)
    
    -- 3. Render filled 3D faces and/or outline
    box3d.draw_faces(screenPoints)
    box3d.draw_outline(screenPoints)
end)
```

---

## Properties

| Property | Type | Default Value | Description |
| :--- | :--- | :--- | :--- |
| `box3d.thickness` | `number` | `2` | Line thickness for drawing wireframe face outlines. |
| `box3d.color_filled` | `Color3` | `RGB(118, 0, 118)` | Fill color applied to 3D box faces. |
| `box3d.color_outline` | `Color3` | `RGB(50, 0, 150)` | Border line color applied to wireframe quads. |

## API Reference

### `box3d.rotate(cf, offset)`

Transforms a local 3D offset relative to a CFrame into world space position vector.

```luau
box3d.rotate(cf: CFrame, offset: Vector3): Vector3
```

- **Parameters:**
  - `cf`: The reference `CFrame` orientation/position.
  - `offset`: A relative `Vector3` position relative to the CFrame coordinate frame.
- **Returns:** World-space `Vector3`.

---

### `box3d.outline(part)`

Calculates the 8 world-space corner points of a `BasePart`.

```luau
box3d.outline(part: BasePart): {Vector3}
```

- **Parameters:**
  - `part`: The `BasePart` to calculate bounding box corners for.
- **Returns:** An array of 8 `Vector3` world coordinates representing the 8 vertices of the bounding box.

#### Corner Index Map
1. **Front Top Right** `(+X, +Y, -Z)`
2. **Front Top Left** `(-X, +Y, -Z)`
3. **Front Bottom Left** `(-X, -Y, -Z)`
4. **Front Bottom Right** `(+X, -Y, -Z)`
5. **Back Top Right** `(+X, +Y, +Z)`
6. **Back Top Left** `(-X, +Y, +Z)`
7. **Back Bottom Left** `(-X, -Y, +Z)`
8. **Back Bottom Right** `(+X, -Y, +Z)`

---

### `box3d.screen_positions(corners)`

Projects 3D world space corner points into 2D screen positions using `Camera:WorldToScreenPoint`.

```luau
box3d.screen_positions(corners: {Vector3}): {Vector3}
```

- **Parameters:**
  - `corners`: Table of 8 `Vector3` world coordinates.
- **Returns:** Table of 8 projected screen positions (`Vector3` where `X` & `Y` are screen pixels, `Z` is depth/visibility).

---

### `box3d.draw_faces(screen_positions)`

Renders 6 semi-transparent filled quads on-screen forming the full 3D box mesh.

```luau
box3d.draw_faces(screen_positions: {Vector3})
```

- **Parameters:**
  - `screen_positions`: Table of 8 projected 2D screen coordinates generated by `box3d.screen_positions`.

---

### `box3d.draw_outline(screen_positions)`

Renders wireframe quad borders around the 6 faces on-screen.

```luau
box3d.draw_outline(screen_positions: {Vector3})
```

- **Parameters:**
  - `screen_positions`: Table of 8 projected 2D screen coordinates generated by `box3d.screen_positions`.

---

## Face-to-Vertex Index Mapping

Each face is constructed from 4 corner indices passed to `DrawingImmediate`:

| Face ID | Description | Quadrilateral Indices |
| :--- | :--- | :--- |
| **Face 1** | Front Face | `[1], [2], [3], [4]` |
| **Face 2** | Left Face | `[2], [3], [7], [6]` |
| **Face 3** | Back Face | `[5], [6], [7], [8]` |
| **Face 4** | Right Face | `[1], [5], [8], [4]` |
| **Face 5** | Top Face | `[1], [2], [6], [5]` |
| **Face 6** | Bottom Face | `[3], [7], [8], [4]` |
